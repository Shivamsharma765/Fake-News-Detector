How FactLens Works

1
Real-Time Live Web Search:

Queries Google News RSS wires across global news agencies (Reuters, BBC, AP, NASA, The Hindu, NYT) with zero API keys required.

2
Semantic Role & Death Hoax Intelligence:

Distinguishes whether an individual is the actual deceased subject versus someone mourning or giving interviews, and cross-references recognized fact-checkers (FactCheck.org, Snopes, PolitiFact).

3
NLP Linguistic Feature Classification:

Combines live web searches with 5 Scikit-Learn algorithms (Random Forest, Logistic Regression, etc.) trained on 44,898 articles.

About FactLens

FactLens is an AI-powered media credibility and news verification engine designed to combat digital disinformation, fabricated headlines, and celebrity death hoaxes.

Built with high-performance Python, Scikit-Learn, real-time wire verification, and a modern glassmorphic interface.
